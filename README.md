# Deep Learning - Customer Churn Prediction

My first Deep Learning project built to understand how to implement and train a neural network using TensorFlow/Keras.

## 🎯 Project Goal

The main purpose of this project was to learn the practical implementation of a neural network and understand how different layers and activation functions work.
